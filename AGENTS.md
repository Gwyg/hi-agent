# AGENTS.md

## Build & Run
- `cargo build`, `cargo run`, `cargo test` — standard Cargo workflow.

## Architecture
- Single binary crate (`src/main.rs`), no workspace, no library (`lib.rs`).

## Conventions
- Rust edition **2024** (requires Rust 1.85+). There is no `rust-toolchain.toml` to pin a version.
